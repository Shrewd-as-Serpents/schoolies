Decoding Absences · The Coding Matrix

The full instrument, not just its outputs.

The three coded records in the Coding Trail are one application of this instrument. This page is the instrument itself: every code Santos, Grosfoguel, Trouillot, Wolcott, Kirk & Miller, and the information-science literature made available to this audit — whether or not it happened to appear in a passage audited so far.

Wolcott's (2009) transparency standard, which this project already applies to Altheide's textbook, applies here too: publishing the codebook in full, including the parts not yet used, is what makes the coding scheme auditable rather than a set of conclusions asserted after the fact.

Definitions and frameworks sourced directly from data/codebook.json; citations resolve against data/references.json; usage is computed live against data/sage-audit-data.json — nothing on this page is retyped by hand.
