Every code, and where it lands.

This is the finalized instrument as it was actually applied to the 8-record verification queue — not an aspirational superset of it. Two dimensions used in earlier drafts (a fixed extraction-code vocabulary, and a nested-complicity disclosure tier) were dropped entirely when the dataset schema was finalized, rather than kept as unused placeholders, because keeping them would misrepresent what this audit's instrument now measures.

Each tier below is either a controlled vocabulary applied consistently across records (Tiers 1, 2, 4) or an inventory of what the audit actually recorded in free text, explicitly not treated as a fixed code set (Tiers 3, 5).
